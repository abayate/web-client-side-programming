SERVER FILE DETAILS (index.js):
================================================================================

Key Functions:
1. Express Server Initialization
   - const app = express()
   - app.use(express.static(...)) - Serve public files

2. Route Definitions
   - app.get('/', ...) - Home route
   - app.get('/about', ...) - About route
   - app.get('/history', ...) - History route
   - app.get('/achievements', ...) - Achievements route
   - app.get('/api/facts', ...) - API endpoint

3. Error Handling
   - app.get('*', ...) - Catch 404 errors
   - app.use((err, ...) - Global error handler

4. Server Startup
   - app.listen(PORT, callback)
   - Listens on http://localhost:3000

Notable Features:
- Logging of incoming requests
- Console output showing available routes
- Error handling for invalid paths
- JSON API endpoint for dynamic data

================================================================================
TROUBLESHOOTING:
================================================================================

Problem: "Cannot find module 'express'"
Solution: Run "npm install" to install dependencies

Problem: "Port 3000 already in use"
Solution: Change PORT in index.js to 3001 or another available port
          Or kill process using port 3000

Problem: CSS/JavaScript not loading
Solution: Check that public/ folder is in correct location
          Verify file paths in HTML

Problem: 404 errors on static files
Solution: Check public/ folder structure
          Verify app.use(express.static(...)) in index.js

Problem: API endpoint returns 404
Solution: Verify route is defined in index.js
          Check path matches exactly

Problem: Navigation not working
Solution: Check routes are defined
          Verify HTML links point to correct paths
