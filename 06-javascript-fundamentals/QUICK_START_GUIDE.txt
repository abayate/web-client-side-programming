================================================================================
COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "Cannot find module 'express'"
→ Run: npm install

Issue: "Port 3000 already in use"
→ Edit index.js, change: const PORT = 3001;

Issue: Page shows "Cannot GET /"
→ Make sure you're at http://localhost:3000 (not localhost:5000 or other port)

Issue: CSS/JavaScript not loading
→ Check browser console (F12) for errors
→ Verify public/ folder exists with css/ and js/ subfolders

Issue: Facts button doesn't work
→ Open console (F12) to see error messages
→ Check server is running (terminal should show "Server running...")

API ENDPOINTS REFERENCE
================================================================================

GET http://localhost:3000/
→ Returns: index.html (home page)

GET http://localhost:3000/about
→ Returns: about.html (about page)

GET http://localhost:3000/history
→ Returns: history.html (history page)

GET http://localhost:3000/achievements
→ Returns: achievements.html (achievements page)

GET http://localhost:3000/api/facts
→ Returns: JSON
→ Example: {"facts": ["Fact 1", "Fact 2", ...], "count": 5}

GET http://localhost:3000/invalid-page
→ Returns: 404.html (error page)

================================================================================
DEVELOPMENT TIPS
================================================================================

1. Auto-Reload on Changes (Optional)
   Install nodemon globally:
   npm install -g nodemon

   Then run:
   nodemon index.js

   Server will auto-restart when you change files

2. Edit HTML Files
   - Modify views/*.html files
   - Refresh browser to see changes

3. Edit CSS
   - Modify public/css/styles.css
   - Refresh browser to see changes
   - Hold Ctrl+Shift+R for hard refresh

4. Edit JavaScript
   - Modify public/js/scripts.js
   - Refresh browser to see changes
   - Check console (F12) for errors

5. Add New Routes
   - Edit index.js
   - Create new app.get() route
   - Restart server (Ctrl+C, then npm start)
